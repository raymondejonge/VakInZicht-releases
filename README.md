# VakInZicht releases

Publieke, ondertekende updatebestanden voor VakInZicht Kunstvakken.

Deze repository bevat geen broncode en geen gebruikersgegevens. `latest.json` verwijst naar de nieuwste interne Apple-silicon-update. Installaties vertrouwen een bestand alleen wanneer de cryptografische handtekening overeenkomt met de publieke sleutel die in VakInZicht is ingebouwd.

De PKG-installer is beschikbaar voor handmatige installatie of herstel. Deze interne/pilotuitgave is voor macOS met Apple silicon; de app is ad-hoc ondertekend en niet Apple-genotariseerd. Maak vóór installeren een volledige gegevensback-up. Bestaande brugversies kunnen hetzelfde pakket via de ondertekende app-updater ontvangen.
